# DocGuard AI

Document intelligence and compliance/risk analysis
for invoices and contracts.

## Goals
- OCR and document layout processing
- Document classification
- Entity and field extraction
- Explainable document risk checks
- PyTorch and LayoutLMv3 fine-tuning
- Reproducible evaluation and MLflow tracking
- FastAPI backend and Streamlit dashboard

## Development workflow
R&D -> Design -> Implement -> Test -> Evaluate -> Improve

Phase 0: Initial research and design
